# Splash Screen — Mockups

Drop the original splash screen mockup here (PNG, JPG, Koala, etc.).

Final C64-ready assets (converted to hires/multicolor, charset, sprites, etc.)
go in the parent `assets/splash/` folder.

## Naming
- `splash_mockup.png` — main reference image (recommended).
- Additional iterations: `splash_mockup_v2.png`, `splash_mockup_v3.png`, ...

## C64 Constraints (reminder)
- Resolution: 320x200 (hires) or 160x200 (multicolor).
- Palette: 16 fixed C64 colors.
- Multicolor: max 4 colors per 4x8 cell (1 shared bg + 3 per cell).
- Hires: max 2 colors per 8x8 cell.
