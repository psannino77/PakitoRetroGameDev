# Loader Screen — Mockups

Drop the original loader screen mockup here (PNG, JPG, Koala, etc.).

Final C64-ready assets go in the parent `assets/loader/` folder.

## Naming
- `loader_mockup.png` — main reference image.
- Iterations: `loader_mockup_v2.png`, ...

## C64 Constraints (reminder)
- Resolution: 320x200 (hires) or 160x200 (multicolor).
- Palette: 16 fixed C64 colors.
- Loader bar: consider using a sprite or a charset row for the progress bar
  to avoid full bitmap redraws.
